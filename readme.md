# Diário de Consumo Cultural

Projeto em Python criado para registrar e organizar livros, filmes e séries que quero consumir, estou consumindo ou já concluí.

O projeto começou como uma forma de praticar lógica de programação e pretende evoluir conforme avanço nos estudos de Python.

## Funcionalidades atuais

- Adicionar títulos
- Informar o tipo da obra
- Definir o status
- Listar os títulos cadastrados
- Navegar por um menu interativo

## Conceitos praticados

- Variáveis
- Condicionais
- Laços de repetição
- Listas
- Funções
- Entrada de dados com `input()`

## Próximas melhorias

- Editar títulos cadastrados
- Remover títulos
- Adicionar avaliações
- Adicionar comentários
- Salvar os dados em arquivo
- Criar filtros por tipo e status
- Exibir estatísticas do consumo cultural
