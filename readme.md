# diário de Consumo Cultural

programa em Python para gerenciar títulos de livros, filmes e séries que já assisti/li ou pretendo consumir.

este é um projeto contínuo: a ideia é ir evoluindo ele conforme aprendo novos conceitos de programação.

## funcionalidades atuais
- adicionar título
- listar todos os títulos
- remover título
- sair

## próximas melhorias planejadas
- numerar os títulos na listagem
- contador de quantos títulos foram cadastrados
- categorizar por tipo (livro ou filme/série)
